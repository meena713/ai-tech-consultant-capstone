# Evaluation plan

Run 20+ cases per task and enter actual results; do not invent scores.

Task 1: retrieval recall@5, answer correctness, citation support, abstention correctness, latency and failures.
Task 2: classification accuracy, factual correctness, human edit rate, sensitive-case review rate, streak reset after edits, and verify no email-send capability.
Task 3: requirement coverage, native/custom/discovery classification, estimate error against consultant review, follow-up change detection, and approval-gate correctness.

Compare at least two model IDs available to your account using the same frozen cases and prompts. Record exact IDs, correctness, citation support, median latency, token usage, actual API cost, and error rate. Explain the quality/cost/speed trade-off.
